MSU Web Template Suite for Labs, Teams & Faculty

A standalone collection of production-ready HTML and CSS templates crafted specifically for Michigan State University research labs, PI groups, and grant projects. Designed for easy adoption into static site generators (Astro, Gatsby, 11ty) and modern JS frameworks.

Browse Example Pages SSG & AI Integration Guide

Authentic MSU Identity

Official Spartan Green (#18453B), institutional masthead, helmet wordmark, and legal footer meeting MSU Communications & Marketing guidelines.

WCAG 2.1 AA Accessible

Built-in skip links, high-contrast ratios ($\ge 7:1$ and $\ge 4.5:1$), keyboard-friendly focus rings, ARIA landmarks, modal dialogs, and screen-reader status announcements.

SSG & Framework Ready

Zero locked-in CMS runtime. Clean HTML sections and DaisyUI primitives that both human developers and AI assistants can slice directly into Astro, Svelte, or Next.js.

How to Build & Port to Static Site Generators

This template is built so you and your team of programmers (or an AI assistant like Gemini or Claude) can quickly adapt it into Astro, Gatsby, SvelteKit, Next.js, or 11ty.

01 / CLI BUILD

Rebuild or Customize CSS

Compile changes to Tailwind utility classes or DaisyUI themes using the standard npm script:

npm run build:css
02 / STRUCTURE

Semantic Boundary Tags

Every HTML page is annotated with explicit comments making it easy to slice into SSG layouts:

<!-- START: MSU Header -->
<!-- MAIN CONTENT SLOT -->
<!-- START: MSU Footer -->
03 / EXTEND

Add DaisyUI Components

Browse DaisyUI docs, copy standard HTML classes (e.g., btn-primary, card, alert), and they automatically inherit MSU Spartan Green tokens.

04 / WCAG 2.1 AA

Accessibility Guaranteed

Passes automated accessibility testing with verified contrast ratios, semantic landmark roles, native focus outlines, and skip links.
