Accessible Content Elements for SSG Markdown Pages

This page showcases how raw Markdown compiled by tools like Astro, VitePress, or Next.js looks inside the .msu-prose container. All elements meet WCAG 2.1 AA specifications.

1. Headings & Hierarchy

Proper heading hierarchy is required by WCAG criterion 1.3.1 (Info and Relationships). Avoid skipping levels (e.g. from H1 directly to H3) so screen reader users can navigate section landmarks efficiently.

Level 3 Heading (Sub-Section)

Paragraphs are rendered with high contrast body color (#1E293B on white, yielding a contrast ratio $\ge 12:1$) and comfortable line height ($1.75$) to facilitate readability on both mobile and desktop viewports.

2. Lists and Quotations

Standard lists render with generous spacing and high-contrast bullets:

  • Predictive Accuracy: Model achieves state-of-the-art AUROC across variant classes.
  • Generalization: Demonstrates zero-shot transferability across divergent species.
  • Accessibility: Built following Universal Design for Learning guidelines.
"Universal accessibility is not a limitation on design; it is the foundational discipline that makes academic knowledge truly democratic."
— MSU Digital Experience Studio

3. Accessible Data Table

Data tables must feature explicit header cells with scope="col" and a descriptive <caption> element to allow non-visual users to understand tabular associations.

4. Code Blocks & Preformatted Text

Code blocks render with syntax styling and dark Spartan background:

inference.py 
import torch
from msu_genomics import GeoLoopModel

# Load pretrained MSU foundation checkpoint
model = GeoLoopModel.from_pretrained("msu-bio/geoloop-100k")
dna_sequence = "ACGTGGCAGACTGACCTGCA..." 

# Compute variant delta perturbation score
score = model.predict_variant_effect(dna_sequence, pos=14502, ref="A", alt="G")
print(f"Pathogenicity Log-Odds: {score.item():.4f}")

5. WAI-ARIA Accessible Tabbed Content

When organizing dense scientific documentation, use this tab pattern. It complies with the W3C ARIA Authoring Practices Guide (APG) for Tabbed Interfaces, supporting arrow key keyboard navigation:

Compiling CSS via npm CLI

Install project dependencies and build minified CSS to the dist directory:

npm install
npm run build:css

Importing into an Astro Project

Copy dist/css/msu-theme.css into your Astro src/styles/ and import in your main layout:

---
// src/layouts/BaseLayout.astro
import '../styles/msu-theme.css';
---

Static Site Generation with Python (MkDocs / Pelican)

Point your extra CSS stylesheet settings to dist/css/msu-theme.css:

extra_css:
  - css/msu-theme.css
